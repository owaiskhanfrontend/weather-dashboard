# Weather Dashboard
Responsive weather dashboard built from a Figma design.

## Tech:
HTML
CSS
JavaScript
Open-Meteo Weather API
geolocation API

## Features:
- Responsive weather dashboard
- Figma-to-code implementation
- City search
- Current-location detection
- Real-time weather data
- Current weather conditions
- 5-day weather forecast
- Hourly weather forecast
- Day/night weather visualization
- Weather-code based condition mapping
- Animated current-weather visuals
- Static forecast and hourly visuals
- Dark/light theme
- Loading state
- Offline/network handling
- City-not-found error state
- Responsive typography and layouts
- Dynamic temperature, humidity, wind, pressure, UV, sunrise and sunset data
- ES6 module architecture
- Open-Meteo API integration
